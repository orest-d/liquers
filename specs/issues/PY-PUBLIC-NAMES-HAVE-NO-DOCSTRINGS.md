## Problem

`liquers` is mostly PyO3 classes whose `#[pymethods]` items carry no `///` comment, so their
`__doc__` is `None`. A source scan at HEAD (`04667a80`, recorded in `design/py-api-reference/`)
found 40 of the 45 registered classes, 238 of their 285 public methods and properties, all three
native functions (`parse`, `parse_key`, `build_plan`) and all 30 error classes generated by
`liquers-py/python/liquers/_errors.py` `_install` without a docstring. `liquers-py/src/` has no
`text_signature` attribute, and nothing checks coverage.

## Problem Example

```python
import liquers as lq
lq.Query.encode.__doc__      # None
lq.KeyNotFoundError.__doc__  # None (a class made by `type()` in `_install`)
help(lq.Query)               # method names only, no descriptions
```

## Impact

`help()`, editor tooltips and coding agents see bare names for most of the API. The language
integration guide's `DOCS04` ("every public name has documentation") fails, which keeps the
`DOCS` row of `liquers-py/README.md` `PARTIAL`. Workaround: read `specs/guides/PYTHON_GUIDE.md`
or the Rust source.

## Expected behaviour

Every public class, method, property and function in `lq.__all__`, and every generated error
class, has a non-empty `__doc__`; `inspect.signature` works on every public callable; and a test
fails when a public name without a docstring is added.

## Discovery

Split on 2026-10-27 from `PY-API-REFERENCE-NOT-GENERATED` (bulk design): its design,
`design/py-api-reference/`, found that the docstrings and their check need no decision and are
eligible for an automatic fix, while the reference generator waits for the maintainer's choice
of tool. This issue is the docstring half.

## Resolution

Every public class, method, property and function of `liquers` now has a docstring written for a
Python reader, and each generated error class has one (`_errors.py` `_install`). PyO3 already
gave every public callable a signature, so no `text_signature` was needed.
`liquers-py/tests/test_DOCS_docstrings.py` (`test_DOCS04_*`) walks `lq.__all__` and each listed
class's own public attributes and fails on a missing docstring or signature, so coverage cannot
regress. Design `py-docstrings`, branch `claude/project-thread-yi0j65-py-docstrings`; checked with
`bash scripts/test-liquers-py.sh` (213 passed, 6 skipped; 22 Rust unit tests passed).
