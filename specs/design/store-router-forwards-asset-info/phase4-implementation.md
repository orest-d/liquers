## Testing Plan

Each step runs its proof. Then, once: `cargo test -p liquers-core --lib --tests` and
`cargo test -p liquers-store --lib --tests` (the OpenDAL router tests and every caller of the
router), and `cargo check -p liquers-core --target wasm32-unknown-unknown` when that target is
installed (the router impl carries the `?Send` attribute). No `cfg(feature)` or optional dependency
changes, so `scripts/check-build-matrix.sh` is not needed.

## Rollback Plan

All code is in one file; reverting it restores today's router. The tests from Steps 1–5 then fail by
design and are reverted with it. Documents are reverted together with the code; a partial landing
keeps documents unchanged until Step 6.
