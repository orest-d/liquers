# Define UI elements and renderers in JavaScript (UIDEF)

The `UIDEF` feature of `guides/LANGUAGE-INTEGRATION_GUIDE.md` for liquers-web: a page defines element
types that behave like built-in elements in the web backend, and can render the element tree with a
renderer of its own. Requires `web-ui-use` (`UIUSE`).
