# Liquers specs

The folder `memory/` holds the memory's own files: this README, the schema in `_schema/`, the
templates in `_templates/`, the write log in `_log/` and agents' notes in `notes/`. The documents
themselves stay where they are, under `specs/` and `.claude/skills/`; `liquers-specs.yaml`
mounts them. See `specs/reference/AGENT_MEMORY_SERVICE.md`.
