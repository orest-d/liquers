# User guides

*Liquers for Rust*, *Liquers for Python* and *Liquers for the Web* have the same chapters with
the same numbers: chapter 5 is about commands in all three. Language-neutral explanations (the
query language, assets, templates, errors) are written once and appear in every guide. When a
topic does not apply to a language, its chapter keeps its number and says where to look instead.

|---|---|---|---|
| Liquers for Rust | Rust developers building on the crates | [read](rust/index.html) | [EPUB](../downloads/liquers-for-rust.epub), [PDF](../downloads/liquers-for-rust.pdf), [offline HTML](../downloads/liquers-for-rust-offline.zip) |
| Liquers for Python | data scientists and Python developers | [read](python/index.html) | [EPUB](../downloads/liquers-for-python.epub), [PDF](../downloads/liquers-for-python.pdf), [offline HTML](../downloads/liquers-for-python-offline.zip) |
| Liquers for the Web | front-end developers | [read](web/index.html) | [EPUB](../downloads/liquers-for-the-web.epub), [PDF](../downloads/liquers-for-the-web.pdf), [offline HTML](../downloads/liquers-for-the-web-offline.zip) |

Serving Liquers over HTTP is chapter 12 of the Rust guide; calling such a server from a page is
chapter 12 of the Web guide.
