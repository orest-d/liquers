# 11. User interfaces

PURPOSE: The reader knows that the Python package has no user-interface toolkit, and how to show Liquers results from Python or in the interfaces the other guides describe.

## 11.1 Not available from Python

Liquers has a toolkit for user interfaces in which every view is the value of a query, so that
what a user looks at can be bookmarked, shared and restored. It exists for desktop applications
written in Rust and for the browser. The Python package does not include it: there are no
widgets to create and no window to open from Python.

What you have instead depends on where your program runs:

- **In a notebook**, the values a query returns are ordinary Python objects, and the notebook
  shows them as it shows any other: a `polars.DataFrame`, the `view.to_pandas()` of a record
  view, a PIL image. A rendered template (chapter 10) can be shown as Markdown or HTML.
- **In a web page**, Liquers runs in the browser itself, and a page can also call a Liquers
  server. See [chapter 11 of *Liquers for the Web*](../web/11-ui.md).
- **In a desktop application**, see [chapter 11 of *Liquers for Rust*](../rust/11-ui.md).

The queries are the same everywhere. A query that you developed in Python can be given to a web
page or to a desktop application unchanged, provided the commands it uses are registered there.
Commands written in Python exist only in a Python process; chapter 12 discusses how to make
their results available to other programs.
