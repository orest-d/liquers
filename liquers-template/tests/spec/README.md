# Mustache specification

The six required modules of the Mustache specification (`comments`, `delimiters`,
`interpolation`, `inverted`, `partials`, `sections`), copied unchanged from
<https://github.com/mustache/spec> (`specs/*.json`, branch `master`, fetched 2026-10-17) under the
MIT licence in `LICENSE`. `tests/spec.rs` runs every case on `MapHost`.
